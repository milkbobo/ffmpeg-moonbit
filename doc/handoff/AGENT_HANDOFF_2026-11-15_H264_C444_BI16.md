# H.264 4:4:4 B I16 候选

接续 C444_BI4。两种熵模式 batch/stream 的 `intra_in_b` 现已支持
4:4:4，不再需要关闭默认 B 工具。B inter 残差仍为 4x4。

- 新 code_bi16444_residuals：三平面共享 I16 预测模式，每平面独立
  Hadamard DC、4x4 AC、QP 和 intra dequant4 矩阵，预测后重建。
- 共享 luma CBP 只取 0/15；任一平面有 AC 就为三平面编码 AC 列表。
- luma_dc_store 在该私有路径中容纳三组 DC（48 个）；planes_444 存 AC。
- CAVLC 各平面依次 DC/AC，无 chroma mode；nc_block0 新增私有 base 参数。
- CABAC DC 使用 cat 0/6/10、n=48+p，AC 用 cat 1/7/11。
- 删除四个入口剩余的 4:4:4 B 拒收条件，更新旧默认拒收测试。

验证：

- 新专项：纯 DC/带 AC，Y/V 改变而 U 保持平坦，覆盖空平面；
  两种熵模式及 CABAC RD 开关，明确 bi16_mbs > 0；重建闭环，stream/batch
  全字节相等。
- 原 bintra、新 BI16、c444、stream_c444_b 组合回归 21/21。
- native nine-x264 FFI：纯 DC/AC × CAVLC/CABAC，额外验证默认全工具组合，
  逐帧 FFmpeg 像素摘要与本地默认滤波解码一致，零解码诊断。
- moon fmt / moon check --target wasm --deny-warn / moon info --target wasm。
- 无 C ABI 或所有权变化，本轮未运行 ASan。

下一步：B inter 8x8 DCT；更广的高位深、VBV 与默认 B 工具组合回归。
