# MoonFFmpeg 项目申报书

**1. 项目名称**：MoonFFmpeg（仓库 `ffmpeg-moonbit`）——FFmpeg 9.0.2 媒体处理核心的 MoonBit 原生移植。

**2. 项目简介**　截至 2026-11-21，MoonFFmpeg 已用 MoonBit 实现媒体探测、解复用、音视频编解码和封装，并提供缩放、重采样、命令行工具与浏览器演示。项目以 FFmpeg 9.0.2 为主要参考，按功能使用真实码流核对分包、视频像素和音频样本。

**3. 项目方向与通用性**　面向 Web 和工具链的媒体基础软件。MoonBit 库以 Wasm 为交付目标，命令行工具和浏览器工作台共用媒体处理接口。

**4. 预期使用场景**：

- **浏览器在线媒体工具**：拖入 MP4/MKV/TS 即得元数据、封面/缩略图，音频轨转 WAV；全程浏览器内计算，文件不出本机、无后端转码服务。
- **AI Agent 媒体预处理**：Agent 调用 `probe`/`dump-packets`/`decode-audio`/`extract-frame` 命令，直接消费与 `ffprobe` 字段对齐的 JSON 或 PCM/帧数据，无需拼接 FFmpeg 命令行、无需安装本地二进制。
- **边缘与嵌入式**　在具备 Wasm 运行时的设备上，可复用容器解包、缩略图生成与音频转 WAV 的处理流程。
- **教学与科研**：MoonBit 实现逐行对照 FFmpeg C 源码与 ISO/IEC 标准；学生和研究者可查阅真实码流、参考输出及差异排查过程。[移植档案](PORTING_HISTORY.md)

**5. 拟实现的核心功能**：

**解码与容器**　H.264（I/P/B、CABAC、8–14 bit、全色度、MBAFF/PAFF、错误恢复双源矩阵）；HEVC 支持 dependent slice/PCM/RDPCM/CCP/RPLM/persistent Rice；VP9 profile 0–3 帧间与参考缩放；AV1 整帧像素解码（关键帧/inter/superres/qmatrix/帧尺寸变化、film grain 和 intrabc，按夹具对照 dav1d 或 aomdec）；MJPEG、PNG/APNG；AAC-LC/SBR/PS、MP3、FLAC、Opus 全模式；容器读 MP4/MKV/WebM/TS/WAV/Ogg/裸流/HLS/DASH，写 MP4/WebM/TS/WAV/ADTS/fMP4 段/HLS/DASH 清单；位流/哈希/密码算法/`@v128` 内核。

**播放与工具**　统一播放 API 已提供流选择、读包、解码及稳定错误码。CLI 提供探测、分包、解码音频、提取视频帧与封面、HLS/DASH 音频导出。libswresample 支持重采样后导出 WAV，libswscale 支持缩放与 RGB 转换。

**编码与演示**　纯 MoonBit H.264 编码器支持 I/P/B 帧、ABR 与 VBV。AV1 编码器已支持关键帧和帧间帧、多参考帧选择、率失真搜索与去块滤波。浏览器演示已支持探测、封面和缩略图提取及音频导出。当前工作区还实现了 Worker 解码播放、定位、截图、FLAC 导出，以及 H.264 或 HEVC 视频转 MP4。

### 浏览器 Demo 使用方法

安装 MoonBit 工具链和 Python 3。在仓库根目录用 Bash 运行以下命令（Windows 可用 Git Bash）。

```sh
bash scripts/build_demo.sh
python -m http.server 8000 --directory demo
```

用支持 WasmGC 和 JS String Builtins 的浏览器打开 [本地 Demo](http://localhost:8000/)。点击「试用样片」或「选择文件」查看媒体信息，然后按需操作。

- **播放和截图**　点击「Wasm 播放」和「播放视频」，拖动进度条后可点「截取当前帧」。
- **导出音频**　选择 WAV 或 FLAC，点击「生成音频」，完成后下载。
- **转换视频**　选择 MP4（H.264 或 HEVC），点击「转换视频」。WebM 选项使用浏览器自带的编码器。

**后续验收**　继续完善 Wasm 回归与模糊测试，验证浏览器播放和转码对不同输入格式的兼容性。视频和音频已有独立的 `@v128` 内核及标量对照测试，后续将按实测收益接入主路径并形成基准报告。

明确不做：滤镜图/HDR tone mapping、DRM 密钥协商、硬件加速、完整网络协议、AAC USAC、H.264 SP/SI。

**6. 项目性质**：移植项目（工程化再实现）。以 FFmpeg 9.0.2 为参考，按「垂直切片」逐模块移植并用真实码流对拍验收；以 MoonBit 类型系统重写，`@v128` 替代 x86 汇编，未支持项显式报错并附上游源码依据；配套差分测试体系与移植档案为原创工程产物。
